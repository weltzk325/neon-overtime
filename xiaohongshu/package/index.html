02

专属技能 / SKILLS

阿比盖尔 · Q 死线 / R 凝视

Q 蓄力切开直线，重创并处决残血异常；R 标记前方扇形，目标受伤 +30%、移速 -25%。

阿码 · Q 热修复 / R 回车重击

Q 部署终端炮塔并清弹幕；R 突进砸键盘，范围伤害并眩晕。近战靠三连键击贴身输出。

技能冷却与「工会之怒」等升级联动。

03

肉鸽循环 / LOOP

清空房间后选择左右门。门代表下一间的额外奖励：精英掉遗物、资料室出宝箱、事件房有交易、吸烟区回血、自动贩卖机可购买升级。

升级三选一可以重掷；经验来自击杀与清房。金币用于重掷和商店。

清房会回复少量生命；Boss 房入口回复 50% 生命。

04

异常应对 / SURVIVAL

红圈、红线、扇形高亮都是攻击预警。闪避可以穿过弹幕；不要和续命尸站在同一条直线上。

周报魔王三阶段：报表弹幕、盖章追踪、激光扫射、红圈轰炸。阶段切换时会清空一次弹幕，趁机输出。

低血量时屏幕边缘会泛红。活着比 DPS 重要。
